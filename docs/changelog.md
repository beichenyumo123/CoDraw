## MVP v0.1（2026-06-03）— 基础框架

**目标**：跑通「浏览器 ↔ WebSocket ↔ 多人协同画板」核心链路。

**实现功能**：
- ✅ 基于 React + Vite + animal-island-ui 的前端框架搭建
- ✅ FastAPI + WebSocket 后端服务
- ✅ 用户登岛流程（JoinModal → 输入昵称 → 选择角色）
- ✅ 基础绘图工具：铅笔（自由手绘）、矩形、圆形
- ✅ 多人实时同步：一个用户画的内容立即显示在其他用户屏幕上
- ✅ 无限画布：平移（空格+拖拽）与缩放滚轮
- ✅ 动森风格 UI（Banner 顶栏 + NookPhone 手机面板）
- ✅ 一键启动脚本（`start.sh`：后端自启前端 dev server）

**当时架构**：
```
浏览器 ←WS→ FastAPI(app.py) → DRAWING_HISTORY(内存)
         └── 全量广播给所有在线用户
```

## v1.0 — 协同核心（2026-06-03）

**目标**：完善多人协同的基础体验。

### v1.0.1 — UI 交互完善

- 修复 NookPhone 收起状态不同步的 Bug（`217f052`）
- 将 `phoneCollapsed` 状态提升到 AppContext 全局管理
- 优化手机面板与顶栏的交互联动

### v1.0.2 — 公屏聊天（`8cb7385`）

- 新增 `ChatPanel` 聊天组件，支持多人实时文字交流
- 聊天记录保留最近 100 条，新用户登岛时同步历史
- 输入框字数限制 200 字，防止恶意消息
- 修复若干 UI 布局 Bug，更新 README

### v1.0.3 — 用户专属撤销（`ccded05`）

- 初始版本撤销会误删他人图形 → 改为按 `userId` 过滤
- 引入**软删除**（`deleted` 字段），保留历史用于回滚
- 每个图形分配唯一 `shapeId`（UUID），广播 `broadcast_undo` 精确通知

**关键技术决策**：
- 采用软删除而非物理删除，支持未来"时间胶囊回放"功能
- 撤销事件不按索引而按 `shapeId` 定位，避免并发冲突

## v1.2 — 高级功能（2026-06-03）

**目标**：突破简单画板，增加专业级特性。

### v1.2.1 — AOI 视口广播（`a390132`）

- **背景**：全量广播在高并发时浪费大量带宽
- **实现**：客户端上报视口范围（`viewport_update`），服务端按视口过滤广播
- 视口外扩 50% 缓冲边界，防止边缘闪烁
- 光标、图形均走 AOI 广播，大幅降低无效消息量

### v1.2.2 — 梦境番地（Dream Address）

- 一键保存当前画布状态，生成 8 位访问码
- 支持加载他人梦境（只读模式），浏览历史画作
- 基于内存字典存储，适合小型演示场景

### v1.2.3 — 框选区域导出

- 支持框选（Selection）工具选取画布区域
- 导出选中区域为 PNG 图片，自动添加动森风格相框

### v1.2.4 — 像素画网格 + 音效协同（`f1fecfd`）

- 新增 `PixelPanel`：16×16 像素画编辑器，点击填色
- 像素数据二进制压缩传输，减少带宽消耗
- **音效协同**：`broadcast_sfx` 广播画笔、印章、放置等音效，营造沉浸感

**遗留问题**：像素画放置坐标偏移（`v1.2.5` 修复）

### v1.2.5 — Bug 修复周（`fe6cfe8`, `0f454b8`, `41b395e`）

- 修复像素画放置坐标偏移（重构世界坐标转换）
- 修复鼠标指针在 Canvas 上的样式闪烁
- 动森主题光标样式（8 种 `--ac-*` SVG 光标）
- 优化布局：Banner 彩带效果、调色板折叠动画
- 增加一键启动脚本 `start.sh`，降低部署门槛

## v1.4 — 性能优化与测试（2026-06-08）

**目标**：工业化、生产化打磨。

### v1.4.1 — 广播背压机制

- 引入 `asyncio.Semaphore(100)` 限制并发广播数
- 所有广播改为 `asyncio.create_task`，接收循环不再被广播阻塞
- `manager.broadcast()` / `broadcast_aoi_shape()` / `broadcast_aoi_cursor()` 全部受信号量保护

### v1.4.2 — WebSocket 自动重连

- 指数退避：1s → 2s → 4s → 8s → 10s（上限）
- 最多尝试 5 次，超出后提示用户刷新
- `close(1000)` 主动断开不触发重连
- 新增 `isConnected` / `isReconnecting` 状态暴露给 UI

### v1.4.3 — 画笔消息节流

- 铅笔工具 WS 广播加 50ms 节流
- 本地绘制不节流（保持跟手感），仅限制网络发送
- 鼠标抬起时发送完整折线，中间截断不影响最终效果

### v1.4.4 — Retina 适配

- Canvas 分辨率硬编码 `* 2` → `window.devicePixelRatio`
- 修复 `PixelPanel` 像素画编辑器的 Retina 适配
- 修复 `InfiniteCanvas` 主画布的 Retina 适配

### v1.4.5 — 内存安全

- `MAX_DRAWING_HISTORY = 10000`，防止历史无限增长
- `MAX_CHAT_HISTORY = 100` 已有，保持不变
- 压力测试脚本：`tests/benchmark_client.py` + `tests/test_ws.py`

## 总结

从 MVP 到 v1.4 的演进遵循一条清晰的主线：

1. **先跑通**（v0.1）：WebSocket 链路打通，一个人能画，别人能看见
2. **再丰富**（v1.0–v1.1）：聊天、撤销、印章、打字气泡——让协同更好用
3. **再深入**（v1.2）：AOI 性能优化、像素画、音效、梦境存档——专业画板能力
4. **再沉淀**（v1.3）：时间胶囊回放——创作过程本身成为作品
5. **再打磨**（v1.4）：背压、重连、节流、Retina、内存安全——生产级质量
