# 🏝️ CoDraw — 无人岛无限画布协同画板

> 集合啦！基于 **React + FastAPI + WebSocket** 的实时多人协作画板，  
> UI 采用 [animal-island-ui](https://github.com/guokaigdg/animal-island-ui.git) 动森组件库 + Tailwind 手写风格。

## ✨ 功能特性

### 🎨 绘图工具

| 工具        | 说明                         |
| ----------- | ---------------------------- |
| ✏️ 神奇铅笔 | 自由手绘                     |
| 🤚 拖拽抓手 | 平移无限画布                 |
| 📦 完美木框 | 绘制矩形                     |
| ⚪ 圆滚树洞 | 绘制圆形                     |
| 🏷️ 手帐印章 | 点击/拖拽放置动森印章        |
| 🎨 像素画   | 16×16 网格编辑器，放置像素画 |
| 🧽 橡皮擦铲 | 擦除                         |

- **16 色预设调色板** — 焦糖褐 / 无人岛绿 / 向日葵黄 / 西瓜红 / 苍翠松针 / 清透浅蓝 / 樱花粉 / 风信子紫 / 蜜柑橙 / 深海蓝 / 沙滩米 / 薰衣草 / 珊瑚红 / 薄荷绿 / 蜂蜜金 / 蓝莓紫
- **自定义颜色** — 顶栏 `+` 按钮弹出取色器，选中自动保存，localStorage 持久化
- **我的颜色** — 展开调色板中独立区域，hover 显示删除按钮，数量自适应
- **笔触 2~30 级** — 顶栏徽章悬停滚轮快捷调节
- **折叠调色板** — 顶栏常驻 6 个快捷色块，点击 ▶ 丝滑展开/收起

### 🏷️ 手帐印章 (Stamp Tool)

选中印章道具后，下方自动展开 8 枚动森主题印章的图案选择器：

| 印章      | 说明            |
| --------- | --------------- |
| 🍃 树叶   | 叶形路径 + 茎线 |
| ⭐ 星星   | 五角星几何      |
| 🦴 化石   | 螺旋壳化石纹    |
| 💰 铃钱   | 钱袋 + 白星     |
| 🏠 小房子 | 三角顶 + 门     |
| ❤️ 爱心   | 贝塞尔心形      |
| 🎣 鱼     | 椭圆身 + 三角尾 |
| 🦋 蝴蝶   | 四翼对称        |

- **点击即放** — 在画布上点击放置 1 枚
- **长按拖拽** — 按住拖拽连续放置，间隔 35 世界单位
- **极简传输** — 每枚印章仅 80 字节 `{ type: 'stamp', stampId, x, y, scale, color }`
- **Canvas 路径渲染** — 使用当前画笔颜色，全平台一致显示

### 🎨 像素画 (Pixel Art)

选中像素画道具后，NookPhone 展开 16×16 网格编辑器：

- **12 色调色板** — 焦糖褐 / 无人岛绿 / 向日葵黄 / 西瓜红 / 苍翠松针 / 清透浅蓝 / 樱花粉 / 风信子紫 / 白 / 黑 / 金色 / 粉红
- **拖拽绘制** — 在小画布上拖拽填充像素格
- **右键擦除** — 右键或 Ctrl+点击擦除单格
- **视口中心放置** — 点击「放置」将像素画发送到当前画布视口中心
- **二进制压缩传输** — 256 像素编码为 512 字节 hex 字符串，高效同步
- **像素画光标** — 选中像素画工具时画布光标变为 2×2 彩色网格图标，提示"点击放置"

### 🗺 无限画布

- Figma 级视口变换（滚轮锚定指针缩放 + Space 拖拽平移）
- Retina 2x 高清渲染 · 60fps `requestAnimationFrame` 驱动
- `ResizeObserver` + debounce 自适应，折叠手机不闪烁
- **全景导出** — 自动计算包围盒，缩放适配 1920×1080 带相框
- **框选导出** — 拖拽矩形选区，导出指定区域（虚线 UI + 半透明填充）
- **3 种相框风格** — 🏡经典 / 🌊海洋 / 🌲森林，画布底部可选

### 👥 多人协同

- WebSocket 毫秒级双向广播
- **用户专属撤销 (P0)** — 每人只能撤销自己的图形，软删除机制
- **AOI 视口广播 (P3)** — 只推送给看得见该区域的用户，含 50% 缓冲区
- 光标追踪（世界坐标，不渲染自己的光标）
- 他人绘制轨迹虚线实时显示
- 断线指数退避重连（1s → 2s → 4s → 8s → 16s 上限，成功后重置）

### 💬 实时打字气泡 (P2)

- 聊天输入时，其他用户光标上方飘出 `...` 动森气泡
- 3s 无输入自动消失，发送消息立即清除

### 📸 快照截断 (P2)

- 新用户只同步最近 300 条图形（`MAX_INIT_HISTORY`），避免加载卡顿

### 🎬 时间胶囊 (Timelapse)

- **回放模式** — 快照当前历史，以加速方式重放从空白画布到完整作品的全过程
- **进度条拖拽** — 动森风格滑块，可拖动跳转到任意时刻
- **播放/暂停** — ▶/⏸ 切换，拖动滑块时自动暂停
- **4 档速度** — 2x / 5x / 10x / 20x，点击切换
- **自动适配视口** — 根据已绘制图形的包围盒平滑调整 pan/zoom，多人跨区域绘画也能全程可见
- **自动退出** — 播放完毕自动暂停，用户可手动退出回到实时画布
- 回放期间隐藏实时协作元素（他人光标、草稿、梦境叠加层），禁止绘画操作

### 💤 梦境番地 (P3)

- **保存** — `POST /dream/save` 生成 8 位番地码（如 `A3K9M7X2`）
- **加载** — 输入番地码，梦境图形以半透明叠加层渲染在画布上
- 叠加层不影响共享画布，不广播给他人，可随时移除
- 支持正常绘画/平移/缩放，一键 🚪 退出

### 💬 公屏聊天

- NookPhone 内嵌，消息气泡（自己绿底靠右 / 他人白底靠左）
- 新消息自动滚底，Enter 发送
- 服务端保留最近 100 条历史，新用户登岛自动同步

### 🎵 动森音效

- `pop` — 按钮点击 · `chirp` — 登岛/重置 · `splat` — 绘制/缩放
- AudioContext 自动 resume，🔊/🔇 一键切换

### 🐾 UI

- [animal-island-ui](https://github.com/guokaigdg/animal-island-ui.git) v0.9.7 Button 组件
- `#F0E6D2` 沙滩背景 + `#4A3728` 焦糖褐粗边框
- `ac-btn` 拟物按钮 3D 按下反馈
- 动森风格滚动条（绿底褐边圆角）
- 8 位经典角色化身（🐶西施惠 🦝狸克 🐿️小润 🐑茶茶丸 🐱杰克 🦊莫妮卡 🐰仰韶 🦅阿波罗）

### 🖱️ 动森主题光标

8 种 SVG 矢量光标，跟随工具自动切换：

| 光标       | 工具      | 说明         |
| ---------- | --------- | ------------ |
| ✏️ 铅笔    | 神奇铅笔  | 笔尖指向左下 |
| 🩷 橡皮    | 橡皮擦铲  | 粉色方块     |
| 🖐️ 手掌    | 拖拽抓手  | 打开的手掌   |
| ✊ 抓取    | 拖拽中    | 闭合爪子     |
| 📌 印章    | 手帐印章  | 小印章图标   |
| 🎨 像素画  | 像素画    | 2×2 彩色网格 |
| ⊕ 十字准星 | 矩形/圆形 | 可爱十字     |

- CSS 自定义属性 `--ac-*` 定义，SVG data URI 内联

- 右键拖拽平移时显示抓取光标

## 🚀 快速启动

**环境**：Python ≥ 3.8 · Node.js ≥ 18

### 一键启动

```bash
./start.sh
```

自动启动前端 Vite + 后端 Uvicorn，`Ctrl+C` 同时关闭。

- 🎨 前端：http://localhost:5173
- ⚙️ API：http://127.0.0.1:8000

### 分别启动

```bash
# 后端
cd backend && pip install -r requirements.txt && python app.py

# 前端
cd frontend && npm install && npm run dev
```

## 🔌 API

### REST

| 方法   | 路径            | 说明                       |
| ------ | --------------- | -------------------------- |
| `GET`  | `/`             | 服务状态                   |
| `GET`  | `/health`       | 健康检查                   |
| `POST` | `/dream/save`   | 保存梦境 → 返回 8 位番地码 |
| `GET`  | `/dream/{code}` | 加载梦境番地               |

### WebSocket `ws://host:8000/ws/{user_id}?username=昵称&avatar=🐱`

**客户端 → 服务端**

| type              | 字段                     | 说明                   |
| ----------------- | ------------------------ | ---------------------- |
| `add_shape`       | `shape`                  | 提交完成的图形         |
| `drawing`         | `shape`                  | 绘制草稿 (`null`=结束) |
| `cursor_move`     | `x, y`                   | 光标世界坐标           |
| `undo`            | —                        | 撤销自己最后一笔 (P0)  |
| `clear`           | —                        | 清空全部图形           |
| `chat_message`    | `text`                   | 聊天 (≤200 字符)       |
| `typing`          | `active`                 | 打字状态 (P2)          |
| `viewport_update` | `xmin, ymin, xmax, ymax` | AOI 视口同步 (P3)      |

**服务端 → 客户端**

| type                | 字段                                                                     | 说明                                         |
| ------------------- | ------------------------------------------------------------------------ | -------------------------------------------- |
| `init`              | `history, chatHistory, users, yourId, yourColor, truncated, totalShapes` | 初始化 (截断)                                |
| `user_list`         | `users`                                                                  | 在线用户变更                                 |
| `broadcast_shape`   | `entry`                                                                  | 新图形 (`{shapeId, userId, shape, deleted}`) |
| `broadcast_drawing` | `userId, shape`                                                          | 他人草稿                                     |
| `broadcast_cursor`  | `userId, x, y, color`                                                    | 光标                                         |
| `broadcast_undo`    | `shapeId`                                                                | 按 ID 撤销 (P0)                              |
| `broadcast_clear`   | —                                                                        | 全量标记删除                                 |
| `broadcast_chat`    | `message`                                                                | 聊天                                         |
| `broadcast_typing`  | `userId, active`                                                         | 打字气泡 (P2)                                |

### 数据格式

```json
// Pencil / Eraser
{ "type": "pencil", "points": [{"x":100,"y":200}], "color": "#4A3728", "width": 6 }

// Rect / Circle
{ "type": "rect",   "x":100,"y":200,"w":150,"h":100, "color": "#7BC7A5", "width": 4 }
{ "type": "circle", "cx":300,"cy":400,"r":80, "color": "#F38181", "width": 5 }

// Stamp (P1)
{ "type": "stamp", "stampId": "leaf", "x": 500, "y": 300, "scale": 1.0, "color": "#4A3728" }

// Pixel Art
{ "type": "pixelart", "pixels": "010203...", "width": 16, "height": 16, "cellSize": 12, "colors": [...], "x": 100, "y": 200 }

// Chat
{ "userId":"abc", "username":"小润", "avatar":"🐱", "color":"#7BC7A5", "text":"hi!", "timestamp":1717400000000 }

// History entry (with P0 undo metadata)
{ "shapeId": "uuid", "userId": "user_abc", "shape": {...}, "deleted": false }
```
